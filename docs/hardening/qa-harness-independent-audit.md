## 2. What the failures do, and do not, demonstrate

### A. Shape/Text: real sparse renders fail the accepted quality gate; not proof of missing rendering

Both engines fail `Q1.shape.D`, `Q1.text.D`, `Q1.text.N` in the unchanged 18-second meaningful-preview poll (`lib/artifacts.mjs:36–70`). Narrow Shape passes. Retained desktop canvas images visibly contain a sphere and the edited text; they are **not wholly blank**. Their sampled maxima are:

| Route    | Chromium max occupancy / entropy | Firefox max occupancy / entropy |
| -------- | -------------------------------- | ------------------------------- |
| Sphere D | 0.029043 / 0.365329              | 0.029025 / 0.365313             |
| Text D   | 0.009411 / 0.117810              | 0.009420 / 0.118772             |
| Text N   | 0.019748 / 0.241943              | 0.021320 / 0.248018             |

These are separate maxima over each retained sample series, not fabricated simultaneous measurements. Required occupancy is ≥0.01 and entropy >0.5, with ≥5 colors. The failures are valid **accepted-plan quality failures**; those numerical thresholds are not normative accessibility requirements or proof of a broken loader. Working cube/WebGL prerequisites and matching successfully loaded local Helvetiker chunk (`4f23cbed7d4b09cfe2f6c35b34b29a3212b283fab0c6ea9d9778693c57fc5401`) exclude a claimed missing-font prerequisite in these attempts. Runtime error arrays for these Text cases are empty.

**Ownership:** parent assigns a bounded renderer/source-framing investigation, reproducing unchanged Sphere/QA/Helvetiker at D/N and comparing geometry, fitting and default animation phase. Preserve pixel samples and cube controls. Return an independently audited app plan if an actual fitting/rendering defect is demonstrated. Do not immediately edit the renderer, replace fixtures/text, shrink these unapproved cases, alter palette/background, force renders or lower thresholds to make this matrix pass. A metric's applicability concern requires explicit plan review, not a harness-side waiver. Evidence: `C,F/diagnostics/Q1.*-pixels.json`, corresponding retained canvas PNGs and Text `font-identity` events; `lib/ui.mjs:223–268`.

### D. Q7 IDREF: literal supplemental-contract failure, not 14 axe violations

All seven Q7 cases fail in both a02 engines despite zero axe violations. `lib/axe.mjs:79–106` checks every DOM IDREF, including `aria-controls` on **closed Radix popover triggers whose content is unmounted**. For example `Q7.E-dom.json` retains an Edit color button with `aria-expanded="false"` and `aria-controls="radix-_r_1_"`, without a mounted target. This strict supplemental rule is explicitly required by the accepted plan; it is not legitimate to exclude closed/hidden controls silently. Conversely, do not describe this as an axe/WCAG failure or an established user-facing accessibility defect merely because the stronger policy failed.

**Ownership:** parent/accessibility owner first reproduces exact closed/open relationships and separates optional closed-popup references from required label/error references. Then propose a narrowly audited app/primitive compatibility plan if the accepted always-valid-IDREF contract is to be met. Do not unilaterally alter Radix, force-mount every portal or remove relationships to appease the scanner. Any proposal to change the supplemental policy requires explicit renewed approval and a fresh baseline, not a relaxed assertion in this repair batch. Preserve all seven failed cells and full DOM/axe evidence meanwhile.

### E. Firefox late-export: demonstrated harness attribution bug; no additional app defect established

Only Firefox adds `Q5.late-export.D/N` failures. Both reach exact UI sentinel recovery, one targeted throw, restoration and post-error Save; retained downloads are reference/after-error projects, not APNGs. Final teardown rejects console text `[BitmapForge] Export error: Error`. Firefox's retained trace also serializes its second argument only as `{preview:'Error'}`; it does **not** retain the Error's message. Chromium's `text()` includes the sentinel. Therefore the existing string-only whitelist cannot distinguish the expected structured Error on Firefox (`lib/runtime.mjs:96–106`). UI evidence supports this diagnosis but cannot retroactively clear those failed cases or prove the unseen argument value.

**Ownership:** QA harness owner, R1 below. Do not change production logging or permit arbitrary Firefox errors.

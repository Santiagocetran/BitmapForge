## 2. Finite interfaces and success contract

### 2.1 Topology, environment and authenticated messages

Supervisor resolves child as `fileURLToPath(new URL('./server.mjs', import.meta.url))`, records realpaths/hashes, and uses `spawn(process.execPath, [serverPath], { detached: true, env: explicitChildEnv, stdio: ['pipe', 'inherit', 'inherit', 'ipc'] })`. No shell or `unref()`. Parent retains an open child stdin pipe through normal operation; it does not end it as the stop transport. This avoids ignored-stdin EOF being an accidental Vite shutdown trigger when inherited `CI !== 'true'`. Preserve inherited CI identity; never force CI=true. IPC/disconnect/stdin-end handling is installed before importing/starting Vite; unexpected stdin end is a failure path. Tests cover inherited non-CI behavior and supervisor loss closing that pipe.

Supervisor creates a fresh cryptographically random `QA_SERVER_SESSION` and includes it explicitly in expected child environment, rather than comparing the pre-injection parent `environment()` to the child. Expected identity comprises the full child QA\_/PLAYWRIGHT_BROWSERS_PATH environment plus derived output/origin, phase/lane/engine/run/attempt/dist, PID/start ticks/PGID/session, original manifest and served-byte hashes. All must match the parent's independently recorded expectations. New output attempt and identity/exit targets must not already exist; reject, never overwrite/reuse stale evidence.

IPC is a finite version1 protocol:

- Parent → child stop: `{ type: 'qa-server-stop', version: 1, session, pid, signal }`, signal only SIGTERM or SIGINT; first valid request wins, repeated valid requests join it without resetting any deadline.
- Child → parent ready: `{ type: 'qa-server-ready', version: 1, session, pid }`, only after original revision/checksum/served-byte validation and while no stop/failure is latched.
- Parent → child failure stop: `{ type: 'qa-server-abort', version: 1, session, pid, reason }`, bounded serialized reason, for parent transport/protocol failure cleanup when the channel remains usable. Never represents success.

No delivery callback or ready message proves close. Unknown type/version/signal, malformed payload, wrong session/PID or illegal ordering **latches failure** at the receiving side; it cannot initiate an authenticated normal stop or count as success. Receiver enters bounded failure cleanup instead. Parent rejects unsolicited duplicate ready after terminal cancellation. Child protocol failure is retained in final identity and nonzero exit; parent protocol failure poisons observer `state.error` immediately.

### 2.4 Child-local finite startup and orphan termination (R2)

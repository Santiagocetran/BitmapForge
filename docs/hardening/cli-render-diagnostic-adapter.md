## Finite budgets / failure persistence

Original bounds remain 60s render + 16s containment inside 80s outer, 1MiB **each** stdout/stderr; decoder commands 20s each, at most two inside 80s artifact outer, 200 decoded frames. No abandoning timeout race, retry, helper edit or added sandbox workaround.

Per cell: 128 files / 64MiB total; 64KiB / four precreated terminal files reserved. Raw diagnostic buffers: <=18, each <=1MiB. Combined scalar JSONL is <=4096 records / 2MiB, each <=16KiB. To avoid parent/observer shared-file races, that existing allowance is partitioned: parent append-only `parent.jsonl` reserves 1600 records / 1MiB; observer/HTTP `events.jsonl` has the remaining 2496 / 1MiB. The parent byte/file reserve is charged **before** other writes. This is a stricter allocation within, not an increase to, the accepted caps. The browser queue is <=64 unacknowledged records / 4MiB pending payload (including base64 transport). Parent sampling is at most once per 50ms, <=1600 iterations per render; retained owned identities <=256 and loopback ports <=32. Any insufficient partition is an explicit capacity failure requiring review, never truncation-as-success.

Output/decode growth is watched externally with a further finalization slack; cap/observer failure signals only a verified owned process group with TERM and still awaits the unchanged helper's returned containment accounting. This is **not** a new helper cancellation API and always fails the diagnostic. The helper retains its own emergency TERM/KILL policy. No host-wide kill or stale-PID kill is permitted. Sampler evidence is appended during child lifetime, not only on success. Command/env and empty events/process/cleanup/observer-status/terminal files exist before spawn. Partial acknowledged records survive a production evaluate throw; missing acknowledgements/crash history are failures, not fabricated trace events.

Session source/response checkpoint objects are hash-deduplicated, <=256 files /128MiB excluding the individually capped cell trees. Runtime inputs and adapter bytes are checked before/after cells; runtime drift invalidates comparison. Test-only owner drift is separately attributed. Every arm keeps original artifacts, decoded RGBA, actual seven-route response bodies and exact URL/origin/port/status/type/hash/size metadata. Observed bodies are `runtime-consumed` only for browser responses; WebM-only unused compression routes are external `provenance-only` GETs. No-preload uses parent `/proc` inode attribution and one external GET per route while the server is alive; missing attribution/body is a blocker, never a held-open server.

Spatial/temporal classification divergence stops the pass. As a conservative observer-effect safeguard, decoded APNG byte differences also block; WebM encoded byte differences do not. Selected decoded WebM cross-arm differences are recorded using the unchanged >16 luma / >=0.005 discriminator, so codec-only sub-threshold noise does not create a blocker. These are diagnostic comparability checks, not replacements or relaxations of artifact gates.
